ℹ️ Tentang MANGGA.WEB

MANGGA.WEB adalah proyek web multifungsi sebagai ruang eksperimen untuk menggabungkan produktivitas, alat digital, permainan, dan antarmuka interaktif dalam satu halaman.

🧰 Produktivitas

Notes, daftar tugas, progres aktivitas, ekspor catatan, serta backup dan pemulihan data.

⚙️ Tool digital

Kalkulator, konverter, pengolah teks, encoder, generator, alat tanggal, matematika, dan utilitas sehari-hari.

🎮 Hiburan

Snake, Tic Tac Toe dengan tingkat kesulitan AI, tebak angka, drawing pad, dan Meteor Blaster.

💻 Terminal lokal

Terminal interaktif untuk menjalankan perintah bawaan aplikasi, melihat status, menghitung ekspresi sederhana, dan mengakses fitur cepat. Ini bukan terminal sistem operasi.

Prinsip proyek: satu file HTML, antarmuka responsif untuk ponsel, mode gelap/terang, dan penyimpanan lokal melalui localStorage. Sebagian besar fitur dapat digunakan tanpa internet; fitur ini tidak memerlukan akun atau backend. Data lokal dapat hilang jika data browser dibersihkan, jadi gunakan fitur backup untuk menyimpan salinan.

Nama proyek: MANGGA.WEB
Tujuan: belajar, berkarya, bereksperimen, dan membuat alat digital yang praktis.
